Creado con la herramienta integrada de generación de imágenes, usando public/images/dog.png como referencia. Hoja original RGBA de 1774 × 887 píxeles, cuadrícula 4 × 2, guardada sin editar ni perder el canal alfa en public/images/dog-sprites.png. Se recorta en pantalla con posiciones CSS. ## Prompt utilizado

Use case: stylized-concept. Asset type: production 2D virtual-pet sprite atlas. Reference image: the curly chocolate-brown dog in the attached photo, identity reference only. Make an ORIGINAL adorable round cartoon puppy with floppy curly ears, big kind eyes, chocolate curly coat, tan muzzle, tiny rounded paws. Simple clean soft 2D mobile game illustration, bold readable silhouette, subtle shading, fully OPAQUE fur/body with genuine transparent alpha BACKGROUND. Create ONE sprite atlas square image exact 4 columns x 2 rows, eight equal square cells, no gutters, no labels or text, no background, no ground shadows. Each puppy centered in its cell, same size and anchor, whole body fits within middle 80% of each cell. Left to right top row: 1 sitting idle eyes open smile; 2 sitting blinking eyes closed smile; 3 sitting very happy open mouth tongue; 4 sitting eating chewing eyes happy. Bottom row left to right: 5 sitting muddy with a few opaque dirt spots; 6 sitting clean bathtime eyes closed cheerful (no bubbles outside silhouette); 7 sleeping curled up eyes closed; 8 joyful airborne jump paws spread. No accessories, collar, scenery, frames, captions, grid lines or checkerboard. Preserve brown curly dog identity across all eight cells. Designed to crop using a precise equal 4x2 grid. Subject pixels fully opaque, only external negative space transparent.
